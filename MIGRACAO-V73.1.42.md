# Migração para V73.1.42

1. Substitua o `index.html` da versão anterior.
2. Mantenha os demais assets do Scout.
3. Faça novo deploy.
4. No desktop, use Ctrl+Shift+R uma vez.
5. No iPhone/iPad, feche e abra novamente o app após a atualização.

## Onde fica a equipe
Menu lateral → **🏟️ Equipe acompanhada**.

## Criar outra equipe
Abra **Equipe acompanhada** → **＋ Nova equipe** → informe o nome → **Criar equipe**.

## Colocar atleta no elenco
Selecione a equipe → **＋ Adicionar atleta** → escolha a ficha → **Adicionar ao elenco**.
