# Migração para V74.3.3

1. Faça backup pela Central de Saúde & Backup.
2. Substitua apenas o `index.html` pelo arquivo V74.3.3.
3. Publique no frontend estático.
4. No Windows: `Ctrl+Shift+R`.
5. Se usar PWA, feche completamente e abra novamente.
6. Abra **Equipe & Temporada** e teste as duas abas.

Nenhuma migração destrutiva de dados é executada. O Analyzer Local V2.3.0 permanece compatível e não precisa ser reinstalado por causa deste hotfix.
