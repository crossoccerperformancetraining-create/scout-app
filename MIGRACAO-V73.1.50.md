# Migração V73.1.49 → V73.1.50

1. Substitua o `index.html` pela versão V73.1.50.
2. Preserve os demais arquivos estáticos do projeto.
3. Publique normalmente.
4. No computador, faça `Ctrl+Shift+R` uma vez.
5. No iPad/iPhone/Android, feche e abra novamente o PWA se a versão anterior permanecer em cache.

## Primeiro teste recomendado
Início → Plano de Análises do Dia → escolher posição → atleta → motivo → prioridade → Adicionar → Analisar → salvar avaliação → voltar ao Início → confirmar mudança automática para Concluído.
