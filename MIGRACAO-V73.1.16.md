# Publicação V73.1.16

Você pode publicar diretamente sobre a V73.1.13, V73.1.14 ou V73.1.15.

Substitua juntos:
- `index.html`
- `sw.js`
- `manifest.json`

Depois:
1. aguarde o GitHub Pages;
2. faça `Ctrl + Shift + R`;
3. confirme **V73.1.16 / 1.3.1.16**;
4. gere o comparativo dos três atletas;
5. confira **Nota / Encaixe / Potencial**;
6. confirme a régua de cinco níveis;
7. gere um individual e confirme o mesmo padrão.
