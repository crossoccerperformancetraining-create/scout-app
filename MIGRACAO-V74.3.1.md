# Migração para V74.3.1

1. Faça backup no Scout antes da atualização.
2. Substitua o `index.html` pela versão V74.3.1.
3. Faça hard refresh no Windows (`Ctrl+Shift+R`) e reabra a PWA/iPad.
4. Em Equipe & Temporada, crie manualmente as equipes que você deseja acompanhar.
5. Use `+ Adicionar atleta` para criar o vínculo de elenco. O campo `Clube atual` só muda se você marcar explicitamente essa opção.
6. Teste uma avaliação com seleção múltipla de frases e salve uma versão final do parecer.
7. Confirme o parecer na Visão geral e no PDF.

A atualização não duplica atletas. `club` continua sendo clube atual/origem; `squadTeam` representa equipe acompanhada.
