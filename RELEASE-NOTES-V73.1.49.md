# Scout Intelligence V73.1.49 — Subperfis de Função

Base: V73.1.48 homologada pelo usuário.

## Novidades
- Novo bloco **Subperfil da função** dentro do Parecer Assistido.
- O banco de frases passa a ser filtrado por posição + subperfil + categoria + busca.
- Subperfis incluídos:
  - Goleiro: Dominante de área / Líbero-construtor / Reativo-1x1.
  - Zagueiro: Construtor / Imposição / Cobertura.
  - Lateral: Ofensivo / Equilibrado / Defensivo.
  - Volante: 1º volante / 2º volante / Híbrido.
  - Meia: Organizador / Meia-atacante / Entrelinhas.
  - Extremo: Pé natural / Invertido / Velocidade-profundidade.
  - Centroavante: Referência / Móvel / Profundidade.
- 84 novas frases específicas de subperfil, sempre adicionadas manualmente pelo scout.
- O subperfil selecionado é persistido como contexto da avaliação (`scoutFunctionSubprofile`) sem alterar nota, decisão ou atributos.
- V73.1.48 de correção fiel, revisão com IA, humanização e síntese executiva preservada.

## Princípio
Subperfil organiza linguagem e contexto de função; não classifica o atleta e não cria evidência.
